# sunlit AI Skills

This repository contains `sunlit`, a CLI-first, AI-operable tool for design-stage ground sunlight analysis.

Agent-specific skill files live in:

- `skills/codex/SKILL.md`
- `skills/claude-code/SKILL.md`

Use those files as the operational instructions. This root `SKILL.md` is only an index so the repository still advertises that AI skill adapters are available.

Product boundary:

`sunlit` is a design-stage reference tool. It is not a permitting tool and does not perform full-window sunlight analysis.
