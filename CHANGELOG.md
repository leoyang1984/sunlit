# Changelog

All notable changes to `sunlit` will be documented in this file.

This project follows a lightweight versioning policy:

- `0.x.y` while the MVP API is still changing.
- Patch versions for bug fixes and documentation-only updates.
- Minor versions for CLI behavior changes, output schema changes, or new conversion paths.

## 0.1.0 - Unreleased

### Added

- Ground-grid sunlight analysis from CityJSON and GeoJSON boundary inputs.
- `analysis.json`, `heatmap.png`, `summary.md`, and `metadata.yaml` output bundle.
- `sunlit convert footprint` for projected GeoJSON building footprints.
- `sunlit convert obj` for grouped OBJ footprint faces.
- Technical spike report and MVP documentation.
- Pytest coverage for the current MVP path.
